# 银白龙娘 · Codex 额度桌宠

你好，我是银白龙娘，住在 Windows 桌面上的 Codex 额度助手。抬头看看我顶上的四格电池，就知道这轮 **5 小时额度**还剩多少、几点重置。额度低时我会收起翅膀，抱着水晶球打瞌睡；额度用完，我就蜷起来睡一会儿。

## 从这里开始

1. 在 Windows x64 电脑安装 Codex 并登录自己的账号。
2. Windows 安装包将在 Releases 中提供。
3. 鼠标悬停可看额度明细。点击水晶球打开菜单，可以调整大小、低额度阈值、提示时长和音效。

## 电池怎么看

灰紫色表示剩余，浅紫白表示已用。每用掉 25% 就少一格，右侧数字显示剩余百分比。电池、重置时间和困倦状态都只跟随 5 小时额度。如果 Codex 暂时没有返回这项数据，桌宠会显示「5 小时额度暂不可用」。

## 和我一起工作

- **直接派单**。双击角色，可以输入任务，也可以用 Windows 听写，校对后发送。桌宠自己发起的任务支持显示结果、停止任务和处理授权请求。
- **跟随已有对话**。水晶球 →「对话绑定」，选择跟随全部或只绑定选中的会话。
- **跟随下一条新对话**。先点「绑定下一条新对话」，再去 Codex 正常开聊。绑定会保存在本机，后续新开的对话不会顶掉它。也可以启用「自动绑定以后每一条新对话」。
- **任务提醒**。完成、失败和授权各有独立提示音，支持替换 WAV、调整音量和免打扰。发布版首次启动会生成三种提示音。

对话列表来自本机 Codex 可见的会话。外部会话通过轮询跟随，写入历史记录后才可能显示提醒。会话绑定已用模拟事件验证，真实账号和不同 Codex 版本下的表现仍待验证。

## 从源码运行

需要带 Tkinter 的 Windows Python 3。在项目目录执行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

桌宠通过本机的 `codex app-server` 读取额度和处理任务。自动查找失败时，可在水晶球设置中填写 `codex.exe` 的完整路径。参与测试或反馈问题时，请勿上传个人会话、登录凭据或 `settings.json`。

这是用户创作、由 Codex 协助实现的桌宠项目，与 OpenAI 官方产品独立。
